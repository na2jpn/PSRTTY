PSRTTY Ver1.06 FIX3 差分ソース
作成日：2026-10-01
基準：PSRTTY 1.06 FIX2（FIX1フルソースにFIX2差分を適用した状態）
バージョン番号は1.06のままです。

適用方法
1. PSRTTYを終了し、現在のソースと設定・ログの控えを残してください。
2. FIX2ソースのpsrtty.pyがあるフォルダーへ、このZIPの内容を同じ構成で上書きしてください。
   FIX1のままの場合は、先にFIX2差分を適用してください。
3. ソース実行、または既存のbuild-windows.ps1でWindows EXEを再ビルドしてください。
このZIPには変更・追加ファイルだけを収録しています。EXEやDLLは含みません。
アプリ内の「PSRTTYのバージョンアップ」に指定するZIPではありません。

変更内容
・Englishで残っていたメインの「C同調」を、値なし／数値表示の双方でC tuningに変更。
・表示 → 最新QSO表示件数の下に「時刻表記」→ JST / UTCを追加。初期JST、選択保存。
  PCの時計から、PCのタイムゾーンに依存せず変換します。
  現在のQSO、受信送信カード、最新QSO、QSOログの表示を切り替えます。
  手動入力日時も同じ交信時点を維持して変換。不正な入力の場合は切替を止めます。
  ADIFはUTCで保存し、既存の生ログTXTとHAMLOG CSVはJSTを維持します。
  ADIF出力期間の初期表示にも反映。Cabrilloなど明示的な日時基準は各画面の表記に従います。
・ファイル → RTTYプリンターを追加（終了の手前）。
  出力有効、印刷する内容（RX／TX／RX+TX）、設定、テスト印刷、印刷待ち消去。
  メインだけを対象とし、サブデコは含みません。起動時の出力は必ずOFF、対象初期RX。
  RXはカード確定時、TXは正常送信完了時に受付。中断したTX全文は印刷しません。
・「指定文字数以下は印刷しない」は初期チェックON・1文字。
  本文の前後の空白・改行を除いた文字数で判定。時刻とRX/TX表記は数えません。
  受信表示やログ保存には影響しません。
・別スレッド＋上限付き待ち行列。初期上限500件、送出間隔0.5秒、32文字幅。
  USBシリアルCOMを指定、初期115200 bps、8N1。対応ファーム用の各行ACK待ちも選択可能。
  無線機・外部制御と同じCOMを拒否。無線機COMの自動探索時も明示指定を案内。
・上限到達や接続エラーは印刷受付を停止し、ステータス欄へ通知。
  通知音・モーダルダイアログ・フォーカス移動なし。送受信とログ保存を継続。
  未処理の待ちは保持し、再開は出力ON。途中で失敗した印刷は自動再送しません。
  OFF／待ち消去／終了は未送出分を取り消し。送出済みは印刷される場合があります。
  待ち行列のディスク保存はありません。停止中の受付漏れ件数はツールチップに表示。
・追加メニュー、設定、状態表示、ガイドを日本語／英語に対応。

プリンターについて
この差分はPCアプリ側です。XIAO等のファーム、配線、プリンター実機確認は含みません。
接続仕様・ファーム担当者への引継ぎ・確認手順：docs/RTTY_PRINTER_PROTOCOL_FIX3.txt
まず出力OFFのままテスト印刷し、速度・行幅・送出間隔を実機に合わせてください。
ACKなしでは実印字完了、紙切れ、装置内部の溢れを確認できません。
ACKは同梱仕様のOK応答に対応するファームでのみ有効にしてください。

検証
・Linux / Python 3.12 / PySide6 6.11.2 / Qt offscreen。
・全体回帰419件、失敗0・エラー0、スキップ1。
  スキップ：この実行環境でローカルソケットを作成できない二重起動IPC試験。
・FIX3追加試験：短文除外、対象選択、印刷順、ワーカースレッド、過負荷停止・再開、
  切断、ACK成功／タイムアウト、部分書込、制御文字除去、OFF・消去・終了、
  時刻の日付境界、手動日時とADIFの整合、既存カード切替、メニュー配置、英語表示など。
・英語プリンター設定画面とメインの追加表示をoffscreen画像で確認。
  日本語フォントのない実行環境のため、日本語の実画面表示はWindowsで確認が必要です。
・構文、ZIP破損、FIX2への上書き一致、SHA-256整合性を確認。
・Windows EXEビルド、無線機接続、プリンター実機での動作は未検証です。
