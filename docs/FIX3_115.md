# PSRTTY 1.15 FIX3 — 2026-10-12

- 複数Profileの設定案内を通常のダイアログへ変更し、Windowsのメッセージボックス通知音を避けます。説明内容と設定画面を開く際に一度だけ表示する動作は維持します。
- TX開始・終了でメーターを消去しないよう変更。接続中は取得対応が確認できた表示枠を維持します。
- 読み取りの一時失敗では直近2秒以内の有効値を使用。それを超えるとALCは灰色、送信中のSWR/PWRは -- とし、古い測定値を表示し続けません。
- TX終了後、最後に取得したSWR/PWRを約1秒保持します。受信中の取得値は保持表示を上書きしません。保持終了後は SWR -- / PWR 0.0 を表示します。
- 新たに送信を開始したら保持表示を終了します。切断・接続先変更で対応情報と保持値を破棄します。
- PWRは小数1桁。単位は付けません。SWR/PWRの表示設定も尊重します。
- メーター説明を8言語で更新します。出力換算表は変更しません。
