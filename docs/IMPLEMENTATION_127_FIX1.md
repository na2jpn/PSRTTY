## RIT

表示中の自動取得間隔は約3秒、非表示時は約5秒です。接続時・ウィンドウを開いた時・明示操作後は間隔を待たず取得します。CAT等が使用中なら延期します。取得中にスライダー等を無効化する処理を廃止し、取得結果または状態が変わった時だけ更新通知します。RIT OFF中も実機操作との同期を維持します。切断・非対応・送信中の操作禁止は維持します。

スライダーの左右に−／＋を追加。STEPは1・2・3・4・5・7・10・15・20 Hz、初期1 Hz。矢印キー、Pageキー、ホイール1ノッチ、数値欄の増減に適用します。スライダーをドラッグした場合は指定位置へ移動します。STEPはProfileごとのadvanced.rit_step_hzへ保存します。保留中の連続クリックは加算し、送受信の排他・接続世代による古い応答の破棄は維持します。

## RST

空白や区切り記号だけで連続するx99形式のRST候補に599があれば599を優先します。299 599、399 599、599 299のいずれも599。候補列を越えた数字は優先判定に使いません。599 123 123の番号123は従来どおり取得し、599 25 CA等のCQ WW処理も維持します。自由文ではRSTと番号が同じ3桁になる曖昧さは残るため、最終入力は利用者が確認・訂正できます。

## HAMLOG

周波数はHAMLOGの公開API転送時に限りMHzの小数点以下3桁へ切り捨てます。DecimalのROUND_DOWNを使用し、21.07982は21.079として送ります。読戻しは数値一致で比較し、21.0790等の表示差を許容します。違う周波数や非数値の読戻しは保存しません。PSRTTYのQSO・ADIF・HAMLOG CSV出力・他の連携先の元精度は変えません。

処理順はCALL→Enter→今回の値を転送→全対象項目照合→自動保存選択時だけSave API（18 | THW_SAVEBOX_OFF）→CALLが空になったことの確認です。手動保存選択時は入力欄に残します。空欄確認は独立したデータベース登録証明ではないため、実機側でログの登録を確認してください。

公開仕様書を再確認：作者配布 https://hamlog.xii.jp/mou/soft/Th527api.zip のHamlogMs.txt。コマンド18はSaveボタンクリック相当、101はCALL読出し、115は先頭空行付き入力内容読出しです。仕様書自体から周波数小数桁の一律制限は断定しません。3桁切り捨ては利用者指定によるPSRTTY側の転送方針です。

設定画面の独立CALL検索・氏名/QTH取得と関連ガイドを削除しました。内部のCALL EnterによるHAMLOG標準検索は維持します。旧検索APIは互換性用に残っていますが画面から呼びません。利用者が入力中の別交信は上書きせず、途中失敗・結果不明の交信を自動で再送しません。既存の転送記録キーには元精度の周波数を使用し、今回の切り捨てによって過去の二重転送防止を無効にしません。

8言語の設定説明・ガイド・履歴と埋め込み英語を更新。音声復調、まとめて／逐次デコードの確定処理、AFSK/FSK送信波形、クラブCSVには変更ありません。ウェブ用ファイルは同梱しません。
