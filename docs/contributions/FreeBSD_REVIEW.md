# FreeBSD対応パッチの取り込み

ユーザー提供のSupportFreeBSD.patchを基に実装しました。提案者による非Windows対応の貢献を保持し、元パッチを同じフォルダーに無改変で同梱しています。元パッチには提案者の氏名が記載されていないため、氏名を推測していません。

原提案：OS別Hamlibライブラリ名・システム共有ライブラリ検索、非Windowsの音声デバイスをバックエンド＋番号で識別、OS既定音声デバイスの解決、設定画面の案内変更と試験。

追加改善：Windowsでは従来の指定DLL・同梱DLLのみを読み込みシステム検索へ切り替えない。非Windowsでも明示パス指定時は別ライブラリへフォールバックしない。sounddeviceの既定デバイスがtuple/list以外の添字取得対応オブジェクトでも解決する。旧非Windows音声設定は同名・同バックエンドで一意の場合だけ引き継ぎ、複数候補は再選択を要求する。

WindowsのWASAPIエンドポイントIDの生成・有効性確認・デバイス解決は従来処理を維持しています。回帰試験を実施しましたが、Windows/FreeBSDの実機で音声・CATを検証したことを意味しません。
