# PSRTTY Ver1.26
2026-10-17

- スペース後に数字・記号が続く場合、FIGS（数字モードへの切替符号）を改めて送るようにしました。
- USOS（スペースで英字へ戻る受信機能）が有効な相手で、コンテストナンバーなどが英字になる問題を修正しました。
- AFSK・FSKキーイング・ダイレクト送信へ適用し、USOSが無効な受信側との互換性も維持します。
- 関連ガイドと更新履歴を8言語で更新しました。

- JARL WW RTTY・CQ WW RTTYの標準マクロで、番号の繰り返しを{SENT}-{SENT}へ変更しました。

- 同じ番号をハイフンで繰り返した受信文から、番号を1個として自動取得するようにしました。

保存済みマクロは自動変更しません。該当テンプレートを再反映するか、必要な箇所を手動で変更してください。

Ver1.25以前の全機能・修正を含みます。
