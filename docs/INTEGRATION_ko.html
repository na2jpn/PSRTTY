HAMLOG / 연동

HAMLOG Ver5.48

Windows Turbo HAMLOG/Win 5.27c부터 공개 API를 사용합니다. HAMLOG 하나와 QSO 입력 창을 열고 두 앱 권한을 맞춥니다. 연동 → HAMLOG 설정의 연결 확인은 응답 창 제목을 표시합니다. 기록 시 전송은 기본 OFF입니다. 기본은 입력만 하므로 HAMLOG에서 직접 저장하며 전송 후 저장 요청도 선택할 수 있습니다. 모든 프로필 공통입니다. ADIF 성공 후 수동/TU73를 같은 경로로 전송하며 송신 번호는 한 번만 증가합니다. CALL, JST 날짜/시간, 양쪽 RST, 주파수, RTTY를 보내고 SENT/RCVD는 Remarks1, 자국 CALL은 Remarks2입니다. 교환을 JCC/JCG로 추측하지 않으며 HAMLOG QSL/Code/GL/Name/QTH는 유지합니다.

입력만 전송하는 모드에서는 다음 QSO 전에 HAMLOG에서 저장하세요. 다른 입력 중 교신은 보호합니다. 자동 저장은 항목 확인 후 Save를 실행합니다. 실패해도 ADIF는 저장되어 있으므로 QSO를 다시 추가하지 말고 HAMLOG를 확인하세요.

실패 복구

이유와 조치를 대화상자로 안내합니다. PSRTTY ADIF는 이미 저장했으므로 QSO를 다시 추가하지 않습니다. 중단 전송은 작업 로그에 남기고 자동 재시도하지 않습니다. HAMLOG 확인 후 누락만 수동 입력하거나 파일 → HAMLOG CSV를 씁니다. HAMLOG 기록/수정/삭제는 역동기화하지 않습니다.

HAMLOG에는 MHz 소수점 이하 3자리로 버림하여 전송합니다(21.07982 → 21.079). PSRTTY ADIF는 원래 정밀도를 유지합니다.

zLog: Z-Server 실시간 연동

HAMLOG 설정에서 599 형식 지정을 켜고 설정란에 RTTY=5*9가 있는지 확인하세요. RTTY가 이미 있어도 확인하세요.

CALL 입력 → Enter 처리 → 이번 교신 내용 반영 → 대조 → Save 순서입니다. Enter로 바뀐 날짜·시간·RST 등은 이후 이번 교신 값으로 설정합니다. 입력란 전송만 선택하면 Save는 수동입니다. 불일치 시 항목·전송값·읽은 값을 표시하고 자동 저장을 중지합니다.

  1. 일반 TCP Z-Server를 실행하고 zLog를 연결하세요. 대회·자국 CALL·교환 번호·시간을 확인합니다.
  2. 연동 메뉴의 zLog 설정에서 서버·포트·고유 단말명·운용자·TX 번호를 지정합니다. 같은 PC는 127.0.0.1입니다. UTC/JST와 소수점을 zLog에 맞추세요.
  3. 새 QSO 전송을 켜고 저장·연결합니다. 기본은 OFF입니다.

수동·TU73 자동 기록 모두 ADIF 저장 후 CALL·시간·RST·송수신 번호·RTTY·밴드·주파수를 보냅니다. CQ WW 주·지역 번호도 그대로 보내지만 대회 해석과 멀티는 zLog에서 확인하세요.

미확인 QSO는 var/zserver-outbox.json에 저장하며 재연결 시 ID와 내용을 대조합니다. 과거 로그와 연동 OFF 중 기록은 자동 전송하지 않습니다. ADIF로 일괄 전달할 수 있으나 같은 QSO를 두 경로로 중복 등록하지 마세요. 서버 확인 후에도 zLog 로그를 확인하세요. TLS·로그인과 역방향 편집·삭제 동기화는 미지원입니다.

ADIF UDP

Log4OM2에서 UDP Inbound의 ADIF MESSAGE를 켜고 포트를 맞추세요. 초기 예: 127.0.0.1(같은 PC), 2236. 수신 설정에 맞게 변경하세요.

새 QSO를 한 번씩 송신합니다. 편집/삭제/과거 로그는 보내지 않습니다. UDP 수신/등록 확인과 자동 재송신은 없습니다. 실패해도 PSRTTY 로그는 유지됩니다.

주파수가 없으면 등록 전에 상대 호출부호와 MHz 입력란을 표시합니다(예: 7.045, 14.085, 50.303). 입력값을 이번 교신의 FREQ에 적용하고 지원 대역표로 BAND를 판정합니다. 저장 후 HAMLOG·ADIF UDP 등에도 같은 값을 전달합니다. 취소하면 등록·전송하지 않습니다. TU73 자동 등록도 같습니다.
