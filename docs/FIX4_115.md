# PSRTTY 1.15 FIX4 — 2026-10-12

- TX中、取得できたALCが開始点未満なら、開始線までの約85%を水色で表示します。視覚的な目安であり、実測した余裕量ではありません。受信中のゼロはこの塗り方を使いません。
- TX終了後のSWR/PWR最終値保持を約2秒へ延長します。受信中の読み取りで保持値を上書きせず、終了後は SWR -- / PWR 0.0 へ切り替えます。
- SWR文字色を1.8以上でオレンジ、2.2以上で朱色、2.8以上で赤へ変更します。境界判定は丸め前の取得値で行います。保持中も色を維持し、-- は通常色。PWRの色は変更しません。
- 接続・TX開始から約1秒後、現在の送信中に正常取得したPWRが0なら、隣に赤字で「Audio設定チェック！」を表示します。出力が正になった時、取得失敗・古い値・RX・切断時は消します。音声設定が原因だと断定する表示ではありません。PWRを非表示にしている場合は読み取りを行わないため案内も出しません。
- 矢印のないUSB入力設定の2つのイラストを、複数Profileの設定案内と初期設定ガイドのオーディオ説明へ掲載します。ICOMの例であり、機種・ファームウェアによる表示差がある旨を注記します。
- 案内文とメーター説明は8言語対応。画像内の日本語はICOMの画面例として共通です。
