# 更新・差分適用

## フルソース

新しいフォルダーへ展開してビルドします。過去のFIXを後から重ねないでください。
ソースZIPには個人設定・QSOログを含めません。

## 実行版

アプリのバージョンアップ機能に対応するrelease ZIPを使用します。
既存のconfig・logdata・varと個人編集ファイルを保護します。Web用ZIPとは別です。
アップデート成功後はvar/updatesが1世代、var/backupsが2世代になるよう整理されます。

## 差分ソース

配布された差分が指定する基準版にのみ適用します。変更されたファイルを相対パスのまま上書きし、
削除対象がある場合はその差分の指示に従います。ビルドと試験はフルソースと同じです。
今後の差分適用案内はこのファイルを更新し、APPLY版別ファイルは追加しません。

## 診断

停止時はvar/diagnosticsの該当ログを確認します。テスト中にPythonが異常終了した場合は、
`python -X faulthandler -m unittest discover -v`で再実行し、例外のスタックを取得します。
1.30のWindows試験では一度アクセス違反が出ましたが、単独・全1120件の再試験とビルドは通過。
原因確定・修正済みとは扱いません。
