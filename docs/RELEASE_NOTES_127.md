# PSRTTY Ver1.27
2026-10-19

- RIT操作を独立ウィンドウへ追加。接続時・受信中の状態を同期し、表示のちらつきを抑えました。−／＋ボタンとSTEP選択にも対応します。
- 登録クラブ一覧を外部CSVへ分離し、確認日と手入力の案内を追加しました。
- 受信カードの単独・繰り返しコールサインの取り込みを改善。DXCCエンティティ名を表示し、連続するRST候補では599を優先します。
- HAMLOG転送の周波数をMHzの小数点以下3桁で切り捨て、照合で保存が止まる問題を修正。独立したCALL検索を削除しました。
- HAMLOG連携設定に599形式の設定例画像とRTTY=5*9を確認する案内を追加しました。
- RYスキマーを追加。ICOMのExtIO IQ入力とRTL-SDR入力から複数のRTTY信号を復調し、縦型スコープにコールサインと国名を表示します。
- RYレーダーを追加。RBNの5接続先を巡回し、J-Clusterと海外2接続先のRTTY情報をバンド別に表示します。現在のバンドを左、ほかのバンドを右へ配置し、情報を30分保持します。
- 両ウィンドウは独立して配置でき、局のダブルクリックで同調します。JA-BAND ONLYを初期ONで追加し、選択状態を保存します。
- RY画面の目盛りをPSLogに合わせて整理。RBNの巡回待ち・接続エラー・巡回番号を明確にし、上海枠をRBN公式配信へ変更しました。
- IQ入力設定にICOM機種別の案内、公式導入ページ、フォルダー内DLL検索を追加。RTL-SDRの導入とHF入力の説明を充実させました。
- メインの機能ボタンを2段に整理。表示メニューのサブデコの下にも、RYスキマー・RYレーダーを追加しました。
- サブデコでは2文字以下の受信断片を表示しないようにし、最新のQSOの見出しにダブルクリックで詳細を開く案内を追加しました。
- 関連画面・説明・更新履歴を8言語で更新しました。

1.26 FIX1までの全機能・修正と、1.27 FIX1〜FIX5を含む正本です。
