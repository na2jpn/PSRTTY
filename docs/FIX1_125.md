# PSRTTY Ver1.25 FIX1 — 2026-10-17

## 適用

先に配布したPSRTTY_1.25_FULL_SOURCE.zipを展開したPSRTTY_1.25_FULL_SOURCEフォルダーへ、差分ZIP内の同名ファイルを上書きしてください。1.24へ直接適用する差分ではありません。設定・プロファイル・ログは含みません。

バージョンは1.25のままです。build-windows.ps1でWindowsビルドを行います。今回の仕様はBUFFERED_RX_125.md、公開用ノートはRELEASE_NOTES_125.mdを参照してください。

## 変更

まとめて受信は、復調フレームの連続性が切れた位置で短い区間を確定し、区間単位で文字数制限を適用します。初回1.25の文字間隔1.5秒の処理を置き換えます。逐次表示はこの区切り通知を無視し、従来の受信途中表示を維持します。ガイド・履歴は8言語で更新しています。

## 検証

Linux / Python 3.12 / PySide6 / Qt offscreen / PortAudioで確認。

- 音声復調を通す新規試験と既存受信表示の関連試験：34件、4.637秒、成功。
- 最終の全体テスト：977件、246.303秒、失敗0・エラー0・スキップ1。
- スキップは既存のローカルソケット／単一起動IPCの環境制約試験。
- 8言語各1345項目の検証、英語フォールバック再生成：成功。
- psrtty・testsのcompileall：成功。

SQ7で1・2・3・4文字の短い音声断片を各々除外し、連続したCQ JA1ABC 599を1回表示・自動取得することを確認。45.45/50 baud、通常/反転、FIGS/LTRS切替、音声ブロックの境界、不正ストップビット、受信イベントの遅延一括処理、世代番号の古い区切り除外も確認しました。逐次の生文字出力とMark待機は維持しています。

Windows EXEと実無線機・実際の受信雑音では別途確認が必要です。連続した正常フレームとして偶然成立するノイズは残ることがあり、すべてのゴミ文字の除去を保証するものではありません。
