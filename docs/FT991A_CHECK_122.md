# FT-991AでのVer1.22確認

現在のCOM・PTT方式・DTR/RTSの割当てを控えてから、次を確認してください。MMTTYと比較する場合は、MMTTYを終了してからPSRTTYを接続します。

1. 無線機が受信状態のときにPSRTTYで接続します。接続が完了するか、接続の瞬間にPTT表示が変化するかを確認します。
2. 最初のFSK送信を開始します。「一瞬PTT ON→OFF→本送信」が残るかを確認します。接続時の変化と送信開始時の変化は分けて記録してください。
3. 一度STOPして、再度送信します。2回目以降も正常に開始・停止できるかを確認します。
4. 通常文、再送、ダイレクト送信のSTOP後の追加入力を確認します。
5. 切断・再接続、Profile切替後にもう一度送信します。選択中のフィルターも維持されるか確認します。

エラーが出た場合は、全文と、どの操作で発生したかを教えてください。Ver1.22では失敗した処理段階が文中に追加されています。特に「接続時」「初回送信時」「2回目以降の送信時」を区別すると切り分けやすくなります。

送信中に「送信中なので切り替えられない」と表示された場合、PTT状態を無視して送信を続けることはしません。
