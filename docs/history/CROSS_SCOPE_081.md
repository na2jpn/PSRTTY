# 0.81 クロススコープ

最新4096サンプルだけを音声スレッドから渡し、表示中のみGUIタイマーで10 Hz更新。FFTのコサイン帯域フィルターでMARK/SPACE音声を分離、共通ゲインでXY描画。窓の中央半分を使用。文字判定・SQには入力しない。周波数変更で古いフレームを破棄。入力停止・0.5秒無更新で消去。

ボタンON/OFF、×、Esc、終了の連動。別ウィンドウを再利用。主スペクトラムの幅・接続を維持。初期設定ガイドに説明を追加。

検証: 既存217件（216成功・1スキップ）、追加テストモジュール18件成功（既存UIフィクスチャの継承テスト15件を含む）。新規固有テスト3件：軸分離・無音、デコード入力不変と周波数変更時クリア、開閉と幅維持・切断なし・古い表示消去。Windows実機の音声入力とEXEビルドは未実施。
