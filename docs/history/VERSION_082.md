# PSRTTY 0.82

## 変更
同調時に線に近い細い楕円を描き、方向別の最新1軌跡を最大0.7秒保持してフェードアウト。5 Hz解析／20 Hzフェード描画は維持。受信位置変更・入力停止・非表示で残光を消去し、同一フレームで寿命を更新しない仕様を保持。

各表示軸の共振応答に、反対側の設定周波数を弱める有限深さのノッチ応答を追加。単純に画面の縦横を縮小する処理ではありません。元の共振帯域を狭めず、シンボル切り替わりへの応答を保ちます。設定周波数からずれると反対軸への応答が増え、位相変化に伴う傾き・厚みの変化が残ります。ノイズ等でも輪郭は乱れます。完全な線ではなく、わずかな厚みを残します。

変更対象はスコープ表示、ガイド、バージョン表記。デコード・送信・日時・ログの動作は変更なし（ADIFのPROGRAMVERSIONのみ0.82へ）。
