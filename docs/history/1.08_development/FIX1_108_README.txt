PSRTTY 1.08 FIX1 — 差分ソース
対象: 前回のPSRTTY 1.08差分を適用済みのソース
利用者向けの版表示: 1.08 / 更新履歴日付: 2026-10-04

変更内容:
・第二AudioOUTを開く前に主AudioOUTの出力先・音量を「保存して開く」で保存します。
・キャンセル、保存失敗、送信中、未保存のProfile構成変更時は開きません。
・保存した主出力先を第二出力の候補から除外します。自動の場合も実際の既定デバイスを解決します。
・機器IDで区別するため、同じ名前の別デバイスは選択可能です。
・主出力と重複した第二出力の旧選択を一覧に再挿入せず、未設定として選び直せます。
・主出力が自動で特定できない場合は、出力先の明示指定を案内します。
・確認・説明・エラー案内は日本語／英語対応。
・1.08の日英更新履歴と同梱変更履歴を2026-10-04に統一。1.07以前の日付は維持。

適用:
ソースをバックアップし、PSRTTYを終了してZIPの中身を1.08ソース直下へ上書き。
build-windows.ps1で再ビルドします。このZIPは差分ソースで、アプリ内更新用ではありません。
config/logdata/varやマクロは同梱・変更しません。

検証:
全467件: 失敗0・エラー0（環境制約のローカルソケット1件スキップ）。
保存成功後だけ開くこと、キャンセル・保存失敗で開かないこと、保存失敗時のメモリー設定復旧、
非アクティブProfileを保存しても使用中Profileを変更しないこと、主デバイス除外、AUTO解決、
同名別機器、旧選択再挿入防止、日付と翻訳を検証。日本語・英語UIを描画確認。
差分の上書き再現と全ソースSHA-256を検査。
Windows EXEビルド、実音声デバイスでの動作はこの環境では未実施です。
