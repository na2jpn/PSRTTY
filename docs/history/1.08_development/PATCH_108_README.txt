PSRTTY Ver1.08 差分ソース / 2026-10-03
対象: PSRTTY 1.07再正本（文字コード修正・タイトル修正済み）

1. ソースフォルダーをバックアップし、PSRTTYを終了します。
2. このZIPを展開し、中身を1.07ソースフォルダーの直下へ上書きします。

3. build-windows.ps1 を実行します。テスト後、EXEとrelease/PSRTTY_1.08.zipを生成します。

このZIPは差分ソースです。単独ではビルドできません。
アプリ内のZIP更新へ指定しないでください。
config/logdata/var、マクロ、Hamlib本体は変更しません。
更新内容はVERSION_108.md、検証内容はVALIDATION_108.mdを参照。
Windowsのタスクバーに古いアイコンが残る場合は、古いピン留めを外して1.08を起動し、留め直してください。
