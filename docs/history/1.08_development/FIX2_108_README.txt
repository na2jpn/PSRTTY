PSRTTY 1.08 FIX2 差分ソース
適用先: 1.08 FIX1適用済みソース
表示バージョン: 1.08 / 更新履歴日付: 2026-10-04

変更:
無線機未接続で「未接続でも送信可」がONかつ第二AudioOUTが有効の場合、
主・第二AudioOUTを独立して開き、使用できる出力先で送信音を再生します。
両方使用可能なら両方へ、片方のみならその出力先へ。両方とも使用不可なら失敗理由を案内します。
出力先の解決、ストリーム作成、開始、再生で失敗しても、もう一方の出力を妨げません。
音量は従来どおり独立。STOPは両方を停止します。同じ実デバイスへの二重出力を防ぎます。
無線機未接続のこの経路ではPTTを操作しません。
第二出力が無効の場合と、無線機接続中の送信は従来の主出力必須の経路を維持します。
日本語・英語の案内、ガイド、1.08の更新履歴へ反映しました。

適用:
ソースのバックアップ後、PSRTTYを終了し、このZIPを1.08 FIX1のソース直下へ上書き。
build-windows.ps1で再ビルドしてください。この差分ZIPはアプリ内更新用ではありません。
config/logdata/var、ログ、マクロは同梱・変更しません。

検証:
全474件: 失敗0・エラー0（環境制約によるローカルソケット1件スキップ）。
追加7件で、両方／主のみ／第二のみ／両方不可、開始・再生失敗、独立音量、
STOP、PTTを呼ばないこと、重複機器、未接続許可OFF、接続中と第二無効の回帰、
メイン画面から第二出力のみの再生まで、英語メッセージを検証。
差分の上書き再現、SHA-256、ZIP整合性を検査。
Windows EXEビルドと実音声デバイスでの動作は、この環境では未実施です。
