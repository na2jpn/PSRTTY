# PSRTTY 0.82 FIX1（最新＋1つ前／0.7秒）

0.82のソースへ上書きし、再ビルドしてください。先に作成した「1本保持・0.8秒」案および「2本保持・0.5秒」案を置き換えるFIX1です。その案を適用済みでも、このZIPを上書きできます。バージョン表記は0.82です。

各方向で最新と1つ前の輪を保持。縦2本・横2本の最大4本です。1つ前の輪は最新に対して45%の明るさを基準に描き、両方とも取得時刻から最大0.7秒でフェードアウトします。新しい輪が届いたら同じ方向の最も古い輪を捨てます。同じ音声フレームの再表示では履歴を増やさず、寿命も延長しません。

同調が安定していれば輪は重なり、変化したときは少しずれて見えます。周波数変更・入力停止・非表示で残光消去。5 Hz解析と20 Hzフェード描画を維持。デコード・送信・ログ処理は変更なし。

関連テスト29件成功。方向別2本上限、前の輪の減光、期限切れ、重複フレーム抑止、周波数変更時消去、文字RTTY信号、既存の表示・デコード入力不変を検証。合成信号のQt描画とフェードを確認し、GIFを同梱。Windows実機の受信音では最終確認が必要です。
