## 変更
- MARK・SPACEそれぞれ最新の軌跡を1つだけ保持。最大約0.4秒で薄く消える残光を追加。

- 受信位置（MARK/SPACE/baud）変更、音声フレーム破棄、スコープ非表示で残光を消去。
- 同じ音声フレームを再表示しても残光の寿命を延長しない。取得時刻から0.4秒で期限切れ。
- 初期設定ガイド更新。デコーダー・送信・日時・ログ処理は変更なし。
