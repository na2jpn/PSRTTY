# PSRTTY Ver1.05 FIX3 差分（試験用）

適用基準：`PSRTTY_1.05_FIX_TEST_SOURCE.zip` を展開したソース。ZIP内の相対パスをそのソースに上書きし、`build-windows.ps1` で再ビルドしてください。FIX2を別途適用する必要はありません。これはソース差分であり、画面内更新用のZIPではありません。

## FIX2も含む

- メインでProfileを選ぶ際、CAT接続に失敗しても選んだProfileを維持し、無線機を未接続と表示します。接続中なら新しい接続を試み、未接続なら自動接続しません。
- 古い周波数をクリアし、TXゲインと受信Mark/Space位置を切り替えます。

## 今回の相談済み変更

- 設定画面の追加ボタンを「＋ Profile追加」にし、高さを確保。追加できるのは合計6件まで。
- 設定画面の下端左に「このProfileを削除」を追加。先頭のProfileと現在使用中のProfileは、理由をダイアログで表示します。その他は確認後にタブを消し、先頭のProfileに表示を移します。保存すると削除確定、キャンセルすると元どおりです。
- メイン右上のProfileボタンを同じサイズに統一。選択中は淡い青地に青枠と青文字、未選択は灰色地に濃い灰色の枠と文字。3件まで1段、4～6件は2段目に配置。
- 設定画面で選択中の親Profileタブと子設定タブの文字をオレンジに変更。

従来の設定ファイルはそのまま読み込みます。先行する1.05試験で7件以上保存済みのデータは読み込み時に削りません。追加は6件未満の場合だけ可能です。Ver1.05は試験中で、正本化は実機確認後です。
