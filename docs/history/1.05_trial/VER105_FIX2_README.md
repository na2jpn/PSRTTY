# PSRTTY Ver1.05 FIX2（動作確認用）

適用基準：前回のVer1.05 FIX試験用ソース。FIX2差分は同じ相対パスへ上書きします。Ver1.05 FIX2全ソースZIPを使う場合は差分を重ねる必要はありません。Windows用バイナリーや画面内更新ZIPではありません。

- メインのProfile切り替えをCAT接続の成功から独立。現在の無線機が未接続なら選択先のProfileへ切り替え、無線機は未接続のまま。接続中なら新しい無線機へ再接続を試み、失敗しても選択先Profileを維持して理由をステータスバーに表示。無線機ボタンから再接続可能。
- 切り替え時に前の無線機の最終周波数を消去し、誤ったQSO記録を防止。Audio OUT送信ゲインと、Profile別の受信Mark/Space位置も反映。旧Ver1.05の設定は読み込み可能。
- 選択中Profileの青いボタン表示を維持。接続できたかどうかは無線機の接続表示で確認。
- 続くFIX3でProfile追加・削除や画面表示を改善。適用方法は `VER105_FIX3_README.md` を参照。

検証：関連テスト26件成功。全体345件中、シリアル依存パッケージ不足により1件起動できず、後からその1件の成功を確認。1件は環境によりskip。Windows実機のCAT接続・切断とAudio経路は実機でご確認ください。
