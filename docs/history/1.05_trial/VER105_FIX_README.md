# PSRTTY Ver1.05 FIX 試験用ソース差分

適用基準：Ver1.04（FIX1・配置修正・C同調ガイド・FIX2・AUTO TRACK移動上限12 Hz／探索範囲±30 Hzを反映済み）。同じ相対パスへ上書きするソース差分です。正本ではなく、Windows用の画面内更新ZIPでもありません。

- 設定画面に親のプロファイルタブを追加。従来の基本設定／無線機／Audio IN／Audio OUT／外部接続／高度な設定は子タブとして保持。
- プロファイル名は英数字1～10文字。初期名Profile1。＋ボタンで現在の設定を複製して追加（最大8件）。名称変更と各設定は画面下の［保存］で確定。
- メイン右上のAudio IN文字表示をプロファイルボタンへ変更。選択中は枠と文字を青で表示。送信・接続・設定操作中の切り替えを拒否。無線機の接続に失敗したら元のプロファイルへ戻す。
- 1.01など旧版の設定はProfile1へ移行。既存設定ファイルとマクロ、ログは保存対象のまま。後続の1.05 FIXは同一バージョン・内容違いの更新機構で扱える。画面内更新に渡すのは、このソースからビルドした正式な配布ZIP。
- 削除／並べ替えは今回対象外。試験段階の差分です。

検証：全344件成功、1件skip（Linuxオフスクリーン環境）。無線機・Audio機器の実機接続とWindowsでの画面配置は利用者側で確認してください。

全ソースZIPは単体でWindowsビルド可能です。差分ZIPからビルドする場合はVer1.04確定ソースに上書きしてください。
