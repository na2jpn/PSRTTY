# PSRTTY Ver1.05 FIX4 差分（試験用）

適用基準：`PSRTTY_1.05_FIX_TEST_SOURCE.zip` に前回の `PSRTTY_1.05_FIX3_DIFF_FROM_FIX_TEST_SOURCE.zip` を上書きしたソース。今回の差分を同じ相対パスへ上書きしてWindowsで再ビルドしてください。画面内更新用ZIPではありません。

今回ユーザーが「FIX2」と呼んだ蓄積分の実装です。配布済みのFIX2・FIX3と取り違えないよう、ファイル名は継続番号FIX4としています。

- 設定画面を開くと、使用中のProfileにかかわらずProfile1の基本設定を最初に表示。使用中のProfileは変えません。
- Profile名に半角英数字に加えて `-` と `/` を許可（合計10文字以内）。古い設定も読み込みます。
- 初期設定ガイドにProfileの操作、切断・再接続と未接続時の表示を追加。
- メイン右上のProfileボタンを高さ18pxに変更。幅108px、3列配置は維持。
- サブデコA/Bの受信文をクリックすると、その行からコールサインを判定できた場合だけメインの相手局CALLに転記。判定不能なら何も変更しません。送信やログ追加は行いません。
- サブデコの行背景を白・ごく薄いグレーで交互に表示。新しい行だけ色を設定し、A/Bそれぞれ150行の上限を維持。

実機では高DPI設定で18pxボタンの文字の見え方、サブデコの誤字を含む行のCALL判定を確認してください。Ver1.05は引き続き試験中です。
