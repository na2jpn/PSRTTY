# PSRTTY 0.81 FIX2

0.81または0.81 FIX1のソースへ上書きし、再ビルドしてください。FIX1のスコープ修正も含みます。0.79には先に0.81差分を適用してください。版表示は0.81のままです。

- クロススコープ更新を10 FPSから5 FPS（200 ms）へ変更。
- 位相補償した受信波形の包絡線が安定した区間を選択。
- 各軸で最大3周期の実測軌跡だけ描き、区間間を結ばない。振幅が変わる多数の輪の重なりを軽減。
- 同調ずれによる楕円の傾きは保持。文字デコードや送信処理は変更なし。
- 無音・古いフレーム・非表示時は消去。安定区間がない雑音などでは表示が減る場合があります。

検証：CQ CQ DE JH1HST JH1HST K 599 599 TU 73 の45.45 baud/170 Hzシフト合成RTTYを5 FPSで描画。39フレーム中、空表示0、両軸表示12。検証用GIFは合成信号です。実際の受信音ではノイズ・フェージングで形が変わります。単一トーンと40 Hz離調、開閉、デコード入力不変もテスト。Windows実機の最終確認は未実施。
