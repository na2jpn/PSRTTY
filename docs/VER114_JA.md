# PSRTTY 1.14 実装仕様

2026-10-10。1.13正本を基礎に実装。

## ダイレクト送信

待機音はITA2 LTRS (31)の繰り返し。送信エンコーダも文字側へ戻し、続く数字でFIGSを再送する。
表示・送信進捗・生ログは入力文字だけ。待機コードで停止時計をリセットしない。
自動STOPは全未送信文字の音声出力完了後に1～9秒（初期2秒）。RTTY文字境界で停止するため、45.45 baudでは最大約0.17秒の遅れを許容する。
新規入力は期限をリセットし、0.5秒の訂正待ち中は停止しない。idle_timeout変更は実行中にも反映する。
ui.direct_idle_secondsを保存。送信済み黒・太字、STOP後の新規部分のみ送信、F12の全文再送、同じ起動中の閉じる／再表示を継承。

## Z-Server連携

新規QSOのADIF保存成功後、zlog.enabledがONなら転送待ちへ追加する。HAMLOGのON/OFFとは独立。
永続化: var/zserver-outbox.json。原子的置換・fsync。破損時は上書きせず、状態と記録時の警告で知らせる。
TCP I/Oは専用スレッド。Qt操作はGUI側のタイマーだけ。RX/TX機器やCAT接続は使わない。
接続先・port（標準23）・pc_name・operator・TX番号（0～15、初期15）・UTC/JST・小数点を保存し、起動時に接続を復元する。
通常TCPのみに対応。TLS/loginは未対応。IP/端末名等は改行やNULを拒否。端末名と運用者名は20文字以内、通信はCP932。
RTTYモード値4、周波数はkHz、バンドは160m～3cmを対応表で符号化。未知のバンドを推測せず、転送不能を通知しADIFを残す。
CALL・日時・RST・生のSENT/RCVD（例05 MA）を渡す。マルチや点数はzLogのコンテスト処理で確認する。自局CALLは受信側で設定する。

## 登録確認と再接続

PUTQSOに明示ACKがないため、GETQSOIDSとGETLOGQSOIDでサーバ登録を読み戻す。
未送信IDの衝突なら別IDへ発番。送信試行済みの場合は同じIDを維持し、IDと主要内容一致なら転送済みとして扱う。
送信前にattemptedを永続化。確認後にキューから除き、除去の保存に失敗した場合はキューへ戻す。
内容不一致は自動再送せず保留する。切断・応答タイムアウトは再接続して照合する。
未確認データがある間は接続先・番号・時刻等の変更を拒否する（連携OFFは可）。
接続先が同じでもコンテストやサーバログを切り替える前に未確認を解消すること。
状態が「接続済み」でも特定zLogの起動・画面・記録までは確認していない。実際のzLogログを確認する。
連携OFF中の新規QSO、過去ログ、PSRTTY/zLogでの既存交信の編集・削除は同期しない。まとめて渡す場合はADIF出力を使用する。同じQSOを両経路で登録しない。

8言語の画面・初期設定ガイド・履歴と埋込み英語を更新。周波数ガイドは1.12/1.13から継承。
