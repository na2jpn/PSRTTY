# PSRTTY Ver1.23
2026-10-16

- FSK用COMを接続時に準備し、接続中は保持するよう変更しました。送信・停止・再送ごとの開閉をなくし、ポート初期化に伴うPTT信号変化の影響を抑えます。
- RTTYモード確認をFSK用COMの準備より先に実行し、初期化後も受信状態を確認してからPTTを開始します。接続解除・Profile切替時にはFSK用COMを解放します。
- FSK送信開始エラーに処理段階を表示します。
- HAMLOG連携を「CALL入力 → Enter → 交信内容反映 → 照合 → Save」の順に修正しました。Enter処理後に今回の日時・RSTなどを設定します。
- HAMLOGの照合エラーに、不一致項目・送信値・読戻し値を表示します。設定画面とガイドに、RTTYのRSTを599形式にする説明を追加しました。
- Hamlibのデバッグ出力を抑制し、ガイド・エラー表示・更新履歴を8言語で更新しました。

Ver1.21以前の全機能・修正を含みます。
