## 1.32 検査（2026-11-02）

- ExtIOの読み取りをStartHWのIQ組数に統一。通常cntとI+Qスカラー数のcntを模擬し、512/1024組、7形式、IQ入れ替えを検査。
- バッファに隣接する領域の目印がコピーされないこと、StartHWが戻る前にポインターを読まないこと、不明な個数で読み取り前に停止することを検査。
- 従来のcntによる長さ計算へ戻した比較用ビルドは、同じ組数試験に失敗。修正した32/64bitはMonoで全自己試験に成功。
- 一時的なレート不一致の回復、3回連続する不一致での停止、レート変更をまたぐ観測の除外を検査。
- Python側でIQ組数を再度半減しないこと、正確な欠落数、8言語のエラー説明、両ブリッジの新検査収録を確認。
- 全体再試験：1,133件、400.890秒、失敗・エラーなし（2件スキップ）。
- スキップは環境制約によるローカルIPC試験と、Windows専用のネイティブ実行試験。ネイティブ32/64bitは同じバイナリの自己試験をMonoで別途実行済み。
- 言語検査：8言語、各1,436項目。Pythonコンパイル検査も成功。
- 凍結Linuxビルド成功。完成バイナリで模擬JA1ABC/JA2XYZを復号。1.92 MS/s・512サンプル単位の3秒入力は5,760,000サンプルを欠落ゼロで処理（最大待ち20.0 ms、処理完了3.021秒）。高レート3秒試験は連続入力性能、別の模擬2局試験は復号を検査。

初回全体試験では試験環境のPyInstaller不足による3件と、高レート連続入力の一時的な欠落による1件がエラー。依存導入後に該当4件を単独で再実行し成功。バッファ量や合否基準は変更していません。

物理無線機・メーカーDLLをこの環境では開いていません。IC-7610のレート一致、周波数目盛り、実局RTTY復号は報告者の実機確認対象です。詳細手順はUPDATE.mdを参照してください。
