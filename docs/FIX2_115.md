# PSRTTY 1.15 FIX2 — 2026-10-12

この累積差分には、先に配布したFIX2の機種選択右寄せと、追加の修正を含みます。

- 機種・Profile選択をメイン画面の表示領域の右端へ配置。狭い画面では列数を調整します。
- RX見出し・ゲージ・状態表示・表示感度を一組にして、スペクトラム下の右端に配置します。表示感度の文字とスライダーを隣接させ、幅が足りない場合は組全体を次の行へ移します。
- 複数Profileの案内に「エラーではありません」の説明を追加します。
- 設定画面の初期サイズを820×850へ拡大。小さい画面では表示領域に合わせ、スクロールできます。
- 無線機操作画面は未接続でも開けます。未接続時は接続を促す案内、接続直後は状態取得中の案内を表示します。
- ALC・SWR・PWRは受信中も取得します。ALCは有効な値を取得できる間、ゼロを含めて表示します。
- SWR・PWRは個別の表示設定に従います。取得できない値、古い値、切断後の値は非表示にします。PWRに単位を付けません。
- 案内とヘルプの説明を8言語すべてで更新します。

## 適用方法

ZIP内の `PSRTTY_1.15_FULL_SOURCE` の内容を、1.15 FIX1、先に配布したFIX2、またはFIX2 UPDATEのソースフォルダーへ上書きし、通常どおりビルドしてください。
設定・ログは含みません。バージョン表示は1.15のままです。

## メーターの注意

受信中も読み出しに成功すれば表示しますが、無線機によっては直前の送信値を保持します。特に受信中のSWR表示は、現在のアンテナSWRを新たに測定した値とは限りません。
ALC開始前の表示は校正した送信ゲインによる目安です。送信していない間は、設定音量から余裕量を推定しません。
対応・尺度の詳細は `METERS_115.md` を参照してください。
