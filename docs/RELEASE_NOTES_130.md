# PSRTTY Ver1.30
公開日：2026-10-23

## RYスキマー
- 細かいIQ入力をまとめて処理し、高サンプリングレートでの受信処理を改善しました。
- 「メイン周波数に連動」を追加しました。ICOM IQは初期ON、RTL-SDRは初期OFFで、入力方式ごとに保存します。
- IQ中心周波数を実際に設定・読み取りし、指定値と異なる場合は赤字で案内します。
- 下部に「IQ受信状況」「復号文」タブを追加しました。直近10秒の状態、入力レート、処理待ち、欠落率を確認できます。
- 受信開始後の処理状況を診断ログに定期記録します。

## マクロ
- 「JARLコンテスト 1」を追加し、従来版を「JARLコンテスト 2」としました。
- 保存済みの編集マクロは維持します。マクロ編集画面で選択・反映できます。

新規表示・更新履歴は8言語対応です。
