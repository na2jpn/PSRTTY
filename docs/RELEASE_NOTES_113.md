# PSRTTY Ver1.13

2026-10-09

## ダイレクト送信の改善

- 送信済み文字を黒字・太字で表示するようにしました。
- 未送信文字をすべて送り終え、追加入力がない状態が2秒続くと、自動でSTOPしてPTTを解除します。
- 待機中に文字を追加すると送信を継続します。入力後0.5秒の訂正猶予中や文字の送信中には、自動STOPしません。
- STOP後に続けて入力した場合、送信済み部分を飛ばし、新しく入力した文字だけを送信します。送信済み文字が重複して送られる問題を修正しました。
- 「再送」またはF12では、全文を先頭から送信します。
- ウィンドウを閉じると送信を停止します。同じアプリ起動中に開き直した場合は、入力内容・送信済み位置・黒字と太字の表示を保持します。
- 入力文字を従来より1ポイント大きくしました。

## メニュー・案内

- ヘルプの「バージョンアップ」の上に区切り線を追加しました。
- 「このソフトについて」のサンクスの隣に「公式サイト PSRTTYへ」ボタンを追加しました。クリックすると既定のブラウザーで公式サイトを開きます。
- 関連する案内と更新履歴を全8言語で更新しました。
- 「このソフトについて」のバージョン表示を、本体のバージョン変数から反映するようにしました。

1.12の8言語対応と世界のRTTY周波数ガイドを継承しています。既存の設定・プロファイル・マクロ・交信ログを引き継ぎます。
