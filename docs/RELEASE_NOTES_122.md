# PSRTTY Ver1.22 — 2026-10-16

- FSK用COMポートを接続時に準備し、接続中は保持するよう変更しました。送信・停止・再送ごとの開閉をなくし、ポート初期化に伴うPTT信号変化の影響を抑えます。
- RTTYモード確認をFSK用COMの準備より先に実行し、初期化後も受信状態を確認してからPTTを開始します。
- 接続解除・Profile切替時にFSK用COMを解放します。送信開始に失敗した場合は、処理段階を表示します。
- エラー表示と更新履歴を8言語で更新しました。

Ver1.21までの全機能・修正を含みます。
