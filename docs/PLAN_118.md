# 1.18 FSK実装・表示方針

標準はAFSK。FSK切替はProfile単位。AFSKの機器・音量・モード設定を維持する。

メーカー取扱説明書を対応判断と実装の根拠とし、選択機種を分類する。
ICOMは32項目でFSK対応、20項目はAFSK。Kenwoodは3機種でFSK対応。Yaesuは10項目でFSK対応、3項目はAFSK。
その他ICOMのように型番が特定されていない項目は、型番とメーカー資料の確認を案内する。
USB信号によるFSKに対応せず、ACC等のFSK入力を持つ機種は適合する外部インターフェース経由で対応する。

利用者向けの画面・履歴では、対応機能へ実機検証の有無だけを理由に暫定ラベルを付けない。
必要な機器・ケーブル・COM・無線機設定を具体的に説明し、実際に直接FSK非対応の機種はAFSKでの運用を明記する。
実機報告による差異が分かった場合は修正し、検証記録へ結果を追記する。

説明色はUSBケーブル1本で使用できる16項目を黒、外部機器・別途音声入力が必要な29項目を青、直接FSK非対応23項目だけを赤にする。
FT-891はUSBケーブルでCAT/FSKを制御できるが受信音声が別接続のため青。
接続を指す場合はUSBケーブル接続と明記する。SSBのUSB、USB-DATA等のモード名やUSB SEND等の実機メニュー名は元の名称を維持する。

機種別根拠は FSK_ICOM_118_FIX3.md、FSK_KENWOOD_118_FIX4.md、FSK_YAESU_118_FIX5.md。
