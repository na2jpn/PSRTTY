# PSRTTY 1.16 FIX5

FIX4適用済みのソースへ上書きする差分です。既存の設定・プロファイル・ログは同梱しません。

- メインの受信ヘッダーを「SQ → チェック → 表示方式 → デコード → 文字数 → 文字以下は無視」の順に配置。
- 表示方式は「逐次／まとめて」。初回・旧設定からの更新時は「まとめて」。選択は保存し、再起動後も引き継ぎます。
- 「まとめて」は改行・約1.5秒の信号途切れで確定後に表示し、指定文字数以下を表示しません。「逐次」は受信中に表示し、短文を確定後に取り除きます。
- 受信途中で切り替えても、受信バッファを維持。確定時のカード・ログ・プリンター・自動取得を重複させません。
- 表示方式変更の保存に失敗した場合は、選択・途中の受信文・プレビューを維持します。
- 生ログとプリンター出力は従来どおり。プリンターの短文除外は独立設定。サブデコの表示方式は変更しません。
- 操作名・ツールチップ・関連ガイド・更新履歴を8言語で更新。日本語は「文字以下は無視」の表記を省略しません。

更新履歴の日付は2026-10-13を維持します。正本化は行っていません。
