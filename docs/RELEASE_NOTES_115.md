# PSRTTY Ver1.15 — 2026-10-12

- Audio IN／OUTの新規設定を明示選択へ変更。既存の自動設定は「自動（旧設定）」として維持します。新規プロファイルでは音声デバイスを選び直します。
- 複数プロファイルで設定を開くと、各無線機に対応する音声デバイスの確認を案内します。設定は現在のプロファイルから開きます。
- Audio OUTの送信テスト横に「接続」を追加。運用接続済みなら追加の接続テストを必須にせず試せます。
- 送信レベルを0～100に変更。低い領域を細かく調整でき、既存の実音量は保持します。0は消音です。
- Audio INの個別保存では同じ選択でも入力を再適用し、設定保存・プロファイル切替でも入力を再開します。
- 上部に取得時のみ表示する小型ALCゲージと2段のSWR／PWR表示を追加。高度な設定でSWR・PWRを個別に非表示にできます。初期値は表示ON、ALCは非表示設定なし、PWRの単位は省略します。
- C同調をSpaceの右へ移動し、枠と太字を解除。従来の数値精度・色分けは維持し、未取得は「-- Hz」と表示します。
- 「未接続でも送信可」をAuto CQの上へ移し、Auto CQにも適用します。出力先の可用性と第二Audio OUTの既存条件は維持します。
- 狭い画面の上部操作を折り返し、プロファイルボタンの列数を調整。設定タブはスクロールできます。
- 8言語の画面・ガイド・更新履歴を更新しました。

- Profile選択を右端へ配置。RXゲージと表示感度を一組で右揃えにし、狭い画面ではまとめて折り返します。設定画面の初期サイズも拡大しました。
- 複数Profileの案内を無音にし、「エラーではありません」の説明とUSB入力設定のイラストを追加。初期設定ガイドにも同じイラストを掲載しました。
- 取得対応が確認できたALC表示枠を接続中は維持。TX中、ALC開始前は開始線までの約85%を水色で表示します。実測した余裕量を示すものではありません。
- SWR/PWRの最終送信値を約2秒保持。保持終了後は `SWR --` / `PWR 0.0`。PWRは小数1桁、単位なしです。
- SWRは1.8以上でオレンジ、2.2以上で朱色、2.8以上で赤。丸め前の取得値で判定します。
- 接続・TX開始から約1秒後、現在のTXで正常取得したPWRが0なら赤字で「Audio設定チェック！」を表示します。取得失敗・古い値・RX・切断時は表示しません。

FIX1～FIX4を統合した1.15正本です。過去のFIX資料は変更経緯として残しています。
