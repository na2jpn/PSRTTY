# PSRTTY Ver1.18

公開日：2026-10-15

## FSKキーイング送信

- ProfileごとにFSKキーイング送信を選べるようになりました。標準はAFSKで、従来の音声設定は保持します。
- FSK出力のCOMポート・DTR/RTS・極性・RTTYモードを設定できます。マクロ・Auto CQ・ダイレクト送信・接続／送信テストに対応します。
- FSK送信では音声出力を使わず、受信は従来どおりAudio INを使用します。
- ICOM 32項目、Kenwood 3機種、Yaesu 10項目でFSKに対応。メーカー資料に基づく接続方法と無線機設定を機種別に案内します。
- USBケーブル接続で使える機種は黒、外部機器が必要な場合は青、直接FSK非対応でAFSKを使う機種は赤で表示します。

## MACROボタン配色

- 表示メニューにMACROボタン配色を追加しました。
- 標準＋3つの名前付きプリセットで、F1～F9の文字色・背景色を設定できます。
- RGB入力・カラーパレットに対応。保存した配色は再起動後も保持し、未保存の変更を破棄する際は確認します。

## ガイド・設定画面

- 初期設定ガイドにFSK専用タブと機種別の説明を追加しました。
- 接続・テスト操作と送信方式の切替を整理しました。複数Profileの音声注意は、AFSKを使用するProfileが2件以上の場合に表示します。
- 接続用のUSBは「USBケーブル接続」と明記し、SSBのUSBモードと区別できる表現にしました。
- 設定・確認画面・ガイド・更新履歴を8言語で整備しました。

既存の設定・交信ログは保持してください。FSKでは、機種により外部インターフェースや受信音声の別接続が必要です。接続条件はソフト内の案内をご確認ください。
