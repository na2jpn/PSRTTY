# PSRTTY 1.27 FIX3 — RYスキマー / RYレーダー

メイン上部は、上段「コントロール／クロススコープ／サブデコ」、下段「空白／RYスキマー／RYレーダー」です。幅はクロススコープ基準、各ボタンの高さはプロファイル切替と同じ22pxです。

両ウィンドウは独立して配置できます。コントロールを閉じても残り、位置・大きさを保存します。PSRTTY終了時には一緒に閉じます。

## RYスキマー

1. 入力方法を選びます。ICOMのIQ出力対応機、または外部USB SDRです。
2. ドライバーを先に導入し、入力DLLを指定します。
3. 外部RTL-SDRでは「機器を検索」でUSBシリアル番号を選びます。COM番号やPCの物理USBポート番号を選ぶ方式ではありません。
4. IQ中心周波数と表示帯域幅を指定し、「スタート」を押します。入力方法別に設定を保存するので、次回は保存済みの内容で始められます。

通常のAudioINによる受信とは別のIQストリームを使います。HDSDRや外部RTTYスキマーを起動する必要はありません。メーカーExtIO DLLの設定画面が出た場合は、その画面で対象機器・受信系統なども確認してください。

| 入力 | 接続・導入 |
| --- | --- |
| IC-7610 | 専用の背面USB 2 IQ出力端子とメーカーのUSB I/Qパッケージ。ファームウェア1.20以降。通常の音声用USB接続とは別です。 |
| IC-7760 | RFデッキ背面のIQ出力用USB接続と、IC-7760用USB I/Qパッケージ。メーカーDLLの設定も確認してください。 |
| その他のExtIO対応IQ機器 | 機器のExtIO DLLを指定します。IQサンプルをコールバック出力する方式に対応します。音声だけをサウンドカードへ出すExtIO形式は対象外です。 |
| RTL-SDR | Windowsドライバーと、PSRTTYのビット数に合ったrtlsdr.dllおよび依存DLL。同じフォルダーに依存DLLも置きます。メーカーの手順に従って導入してください。 |

ExtIO DLLは32/64ビットを自動判別し、付属の独立プロセスで受けます。PSRTTY本体が64ビットでも32ビットExtIOを使用できます。メーカーのDLL・ドライバーは再配布していません。

RTL-SDRでHFを受信するには対応する機器・入力経路が必要です。Blog V4ではV4対応のライブラリとチューナー入力を使います。V3のHFダイレクトサンプリング等は、機器の説明に合ったI/Q入力を選びます。受信用アンテナは外部SDR側に接続します。

同時に見る範囲は、一つのIQ中心周波数の周囲です。7MHzと14MHzを一つの連続IQ帯域として同時に受ける機能ではありません。45.45 baud / 170Hz、最大12信号を並列復調します。170Hzの二つのピークを時間平均で検出し、近接した候補はまとめます。自動検出に出ない弱い信号は、スコープ内の信号位置をクリックして手動追加できます。

縦方向がRF周波数、横方向が信号強度です。受信文から送信局のコールサイン候補を取り出し、国名を添えます。`DE`の後のコールを優先します。相手局のコールしか含まれない受信文等では、推定が一致しない場合もあるので、下部の受信文も確認できます。

周波数ラベルはMarkのRF周波数です。ダブルクリック時、FSKはその周波数へ、AFSKは選択されたLSB/USBとメイン受信Markトーンに合わせてダイヤル周波数を補正します。RYレーダーは配信元の報告周波数へ直接同調します。送信中や無線機未接続時は同調できません。

IQ入力欠落や中心周波数・サンプルレート変更では復調状態をリセットし、途切れたデータを連続した文字としてつなぎません。処理キューは上限付きで、メイン送受信を待たせません。入力が8秒以上届かない場合は、接続・入力設定を確認する表示になります。

## RYレーダー

スタート時にメインの自局コールを使って、受信用の接続を開始します。レポート投稿機能はありません。

- PSLog 1.20正本と同じRBNの5枠を60秒ずつ巡回します。JG1VGX-8 → JG1VGX-7 → BH4HKZ（上海）→ UA0APV-1 → W3LPL-1です。
- J-Clusterは公開XMLを90秒間隔で読みます。失敗時は間隔を延長し、Retry-Afterがあれば従います。
- 海外はG1FEF-2（DXSpider）とNG7Mへ常時接続します。切断時は待機して再接続します。
- 巡回先の所在地と、報告を受信した局の所在地は同じ意味ではありません。各ノードから重複した情報が届くことがあります。
- RTTYと明記された情報だけを採用します。周波数帯域だけでRTTYと判定しません。CW・FT8・FT4・モード不明は除外します。

接続先は初回に `config/ry_radar_sources.json` へ作成します。画面から接続先を編集する設定はありません。ソフト停止後にUTF-8のJSONを編集して、次のスタートで読み直します。ソフトに同梱する既定値は `psrtty/data/ry_radar_sources.json` です。ユーザーのconfigファイルはアップデート対象外です。

左1/3は接続中の無線機のバンドに自動追従します。上のバンドボタンは右2/3に出すバンド用で、現在のバンドは重複表示しません。無線機未接続でもネットワーク受信と右側の表示は使えます。左には接続を促す表示が出ます。

同じコールサインは同じバンドに一つだけ表示し、新しい報告で周波数と時刻を更新します。別バンドの同じコールは別に表示します。古い報告や同じ報告の再取得では保持時間を延長しません。時間は元の報告時刻から計算します。

| 経過時間 | 文字色 |
| --- | --- |
| 0–3分 | 赤 |
| 3–6分 | 朱 |
| 6–12分 | 桃 |
| 12–24分 | 橙 |
| 24–30分 | 灰 |
| 30分以上 | 消去 |

新しい報告を受けると再び赤になります。バンド名を見出しに置き、21.078MHzは`.078`のように表示します。詳細には完全な周波数と報告元・UTC時刻を表示します。

両画面ともラベルが重なれば位置をずらし、本来の周波数位置と線で結びます。単クリックは詳細表示、ダブルクリックは同調です。ずらした画面位置から周波数を逆算せず、保存されたHz値を使います。自動で現在のQSO欄へコールを入れる機能は追加していません。

## サブデコ

サブデコA/Bの表示は空白を除いて3文字以上の受信断片から表示します。2文字以下は内部復調を続けつつ表示しません。メインの「まとめて／逐次」や、その「○文字以下は無視」の判定処理は変更していません。
