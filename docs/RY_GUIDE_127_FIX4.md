## 接続先と状態

上海枠をRBN公式 `telnet.reversebeacon.net:7000` に変更しました。
7000番は公式にCW/RTTY用と案内されています。PSRTTYはRTTYと明記された報告のみ採用します。
5接続先を60秒ずつ巡回する構成と、別のクラスタ受信構成は維持しています。
旧配布と完全一致する上海設定のみ自動移行し、元JSONのバックアップを作ります。
利用者が編集した設定は保持します。

巡回番号と現在の接続先を表示し、通常の巡回終了は「巡回待ち」になります。
DNSエラー・タイムアウト・サーバーからの途中切断は「接続エラー」として残し、次の試行時に解除します。
RBNでエラーになった接続先も次の巡回で再試行します。常時接続のクラスタは従来の待機後に再接続します。
JG1VGXの2ノードは運営者ページに同じアドレス／ポートが掲載されていることを確認しました。
この実装環境からはTelnet先を名前解決できず、実稼働の確認は含みません。

## IQ入力設定

ICOMはIC-7610 / IC-7760の機種選択に応じて、公式I/Qパッケージへのリンクと使用端子を案内します。
IC-7610はUSB 2（通常のCAT / USB Audio用USB 1とは別、ファームウェア1.20以降）。
IC-7760はRFデッキ背面のIQ用USB端子です。
USBはケーブル接続の意味で、SSBの上側波帯とは区別しています。
ICOMでは使わないシリアル番号・SDR入力の行を隠します。

外部入力のラベルはRTL-SDRに限定しました。RTL2832U系を対象とします。
Zadig / WinUSB、DLLの32/64ビット、USBシリアル番号、V3のQ入力とV4のチューナー入力を説明します。
他の機器用ドライバーを置き換えないよう、対象RTL-SDRのBulk-In Interface 0を選択します。
DLL一式を同じフォルダーへ置き、DLL選択→機器を検索→シリアル選択の順に進みます。

フォルダー内DLL検索は、利用者が指定したフォルダーと2階層下までが対象です。
ICOMではExtIOで始まるDLL、RTLではrtlsdr.dll / librtlsdr.dllを候補表示します。
DLLやドライバーを自動インストール・再配布する機能ではありません。
IQ中心周波数と表示幅の例を追加し、説明はスクロール、戻る／スタートは固定表示にしました。
画面内の案内は8言語対応です。
