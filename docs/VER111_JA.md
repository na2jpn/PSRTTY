# PSRTTY 1.11

2026-10-08　Ver1.11
・画面表示とガイド・説明・警告を見直し、5言語の文言をlanguageフォルダーの言語別JSONへ外部化しました。
・初期言語は日本語です。言語ファイルが読めない場合は英語で表示し、項目の不足・不正はその項目だけ英語で表示します。
・全項目の英語を本体にも保持します。選択言語は変更せず、ファイル復旧後は次回起動で元の言語に戻ります。
・読み込み失敗は一度案内し、詳細はvar/language.logに記録します。配布と更新に5言語ファイルを含めます。

## 言語ファイル

language/ja.json、en.json、ru.json、zh.json、ko.jsonを同梱します。
各ファイルはformat=1、language=言語コード、strings=共通キーと訳文の辞書です。
文字コードはUTF-8（BOMも読み込み可）。ファイルサイズ上限4MiBです。
メニュー、設定、サブデコ、出力、ガイド、About、履歴、警告を共通の読み込みで表示します。
無線用の共通表記（Audio IN/OUT、Good、ALC、RST、CALL等）は維持します。

## 失敗時

初回は日本語、以降は保存済み設定を使用し、言語変更は次回起動から反映します。
ファイル欠落・JSON破損・重複キー・形式/言語不一致は英語へ切替えます。
欠落項目・空の訳文・差し込みフィールド不一致・HTMLの閉じ忘れ等は項目単位で英語へ戻します。
外部en.jsonが読めなくても本体の全英語辞書を使います。
選択言語設定は保持します。修復後の次回起動で元の言語に戻ります。
ファイル単位の失敗は一度だけ案内し、項目ごとに案内を連発しません。
詳細はvar/language.log、1MiBでlanguage.log.1へローテーションします。
ログ記録失敗でも起動を続けます。

## ビルドと更新

validate_languages.pyは5言語と差し込み/HTMLを検査します。
--generateで同じen.jsonから本体の英語代替辞書を作成します。
build-windows.ps1は検査・生成・全テスト・PyInstaller・配布ZIP生成を実行します。
配布ZIPとversionupの更新対象に5言語を含めます。1.11以降の不完全なZIPは拒否します。
既存の設定・プロファイル・マクロ・ログを維持します。
