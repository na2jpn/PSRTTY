# PSRTTY Ver1.14

2026-10-10

## ダイレクト送信

- 待機信号をMARK連続からLTRSの繰り返しへ変更し、MARKとSPACEの両方を出すようにしました。
- 待機後に数字・記号を送る際のFIGS切替を維持します。待機LTRSは入力文字・送信済み表示・生ログへ追加せず、自動STOPの時間も延長しません。
- 自動STOPまでの時間を1～9秒から選べるようにしました。初期値は2秒で、再起動後も選択を保持します。
- 入力後0.5秒の訂正猶予、STOP後の新規部分だけの送信、再送時の全文送信を継承します。未送信文字や送信中の文字がある間は自動STOPしません。

## zLog連携

- zLog連携を、PSRTTYからZ-Serverへ交信を直接送り、接続中のzLogにリアルタイム登録する方式へ変更しました。
- 接続設定画面を作り直し、接続先・ポート・端末名・オペレーター・TX番号・UTC/JST・小数点、接続状態と未確認件数を追加しました。初期値は連携OFFです。
- 手動記録・TU73による自動記録とも、ADIF保存成功後に新しい交信を渡します。
- 切断時の交信を保存し、再接続時にサーバのIDと交信内容を照合します。送信直後に切れた場合も、登録済みと確認できれば重複送信しません。
- 既存のzLog向けADIF出力は継続して利用できます。
- 関連画面・説明・初期設定ガイド・更新履歴を全8言語で更新しました。

Z-Serverの通常TCP接続に対応します。TLS・ログイン付き接続と、zLogからPSRTTYへの編集・削除同期は未対応です。zLog側のコンテスト・自局CALL・時刻設定は合わせてください。
