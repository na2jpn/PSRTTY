# 1.10 ビルド画面確認

1. Languageで日本語／English／Русский／简体中文／한국어を選び、再起動して保存を確認します。
2. メイン、設定各タブ、ダイレクト、ガイド、ショートカットガイドの文字欠け・折り返し・スクロールを確認します。追加3言語には英語参照文が残る確認用段階です。
3. 未接続送信でALCの灰色＋無線機確認（各言語）が表示され、停止するとRXへ戻ることを確認します。スペクトラムは継続します。
4. ALC取得可能な実無線機でAudio OUTの開始点を確認し、少し下げて保存します。通常TXのGood／配色が設定画面と一致することを確認します。
5. プロファイル／主出力先／無線機設定を変更した場合に、以前の校正でGoodにならないことを確認します。

公開日は未指定です。確認後の指摘は1.10へ反映します。
