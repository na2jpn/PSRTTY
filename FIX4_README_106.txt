PSRTTY Ver1.06 FIX4 差分ソース
作成日：2026-10-02（JST）
基準：動作確認済みの1.06 FIX3適用済みソース
バージョン番号は1.06を維持しています。

適用方法
1. PSRTTYを終了し、ソースの控えを残してください。
2. このZIPを展開し、FIX3ソースのpsrtty.pyがある場所へ同じ構成で上書きしてください。
3. ソース実行、または既存のbuild-windows.ps1でWindows EXEを再ビルドしてください。
変更・追加ファイルのみのソース差分です。EXEやDLLは含みません。
アプリ内の「PSRTTYのバージョンアップ」に指定するZIPではありません。

1. 短い受信文を非表示
・メインのスケルチとデコードの間に「［0 ▼］字以下は無視」を追加。
・0～10のプルダウン、初期0＝除外なし。1なら1字以下、2なら2字以下を非表示。
・1文字ずつを捨てるのではなく、改行や受信の区切りでまとまった本文を判定。
・既存と同じ本文整形（前後の空白除去・連続空白を1つへ整理）後の字数を数える。
・除外文はメイン一覧と自動取得の対象外。生ログは保持。
・プリンターの短文除外は独立。TXとサブデコの表示には適用しない。
・設定を保存し、次回起動に引継ぎ。保存失敗時は元の設定へ戻す。

2. プリンターの表示整理
・メニューは状態に応じ「プリンター出力を有効にする／無効にする」を切り替える。
・通常の無効時はステータスを非表示。
・有効時は「プリンターが有効：受信のみ（RX）／待ち0件」などで表示。
・設定不備や通信エラー、待ち上限による停止は引き続き状態を表示。
・OFF中のテスト印刷／停止処理中も、待ちがある間は状態を表示。
・明示的なOFFでエラー表示を解除。通知音やダイアログは追加しない。
・「プリンター設定…」を上の設定側へまとめ、罫線は「テスト印刷」の直前へ移動。

3. スペシャルサンクス
・「PSRTTYについて」の最下部にボタンを追加。別ウィンドウを開く。
・謝辞、JS1YCP 秋葉原無線部、JA1YML 草加アマチュア無線クラブ、
  JG1RFE、JH1DUK、JJ1JPE、JN1ATL、JG2AJK、7K2COL、7M2FTRを指定順に表示。
・英語ではAkihabara Amateur Radio Community / Soka Amateur Radio Club。
・ボタンの再操作では同じウィンドウを再利用し、About終了時には一緒に閉じる。

追加機能はすべて日本語／英語対応。ガイドにも説明を追加。
RST-Sのマクロ連動は既存対応済みのため変更していません。

検証環境と制限
Linux / Python 3.12 / PySide6 6.11.2 / Qt offscreen。
全体回帰424件：失敗0、エラー0、スキップ1（二重起動IPCのローカルソケット制約）。
FIX4追加5件も最終再実行して成功。
詳細はdocs/validation/tests106_fix4_full.txt、tests106_fix4_final.txtを参照。
FIX4の追加試験は受信境界・分割受信・除外なし・送信表示・ログ／印刷との独立性、
設定保存／再読込／失敗、日英のプリンター表示・罫線、謝辞の順序とウィンドウを確認。
英語画面を画像でも確認。日本語フォント不足のため日本語実画面はWindows確認が必要。
Windows EXEビルド、無線機・プリンター実機での動作はこの環境では未検証。
FIX3のプリンター接続仕様と実機検証上の制限は引き続き適用されます。
